About Me

Hi, I'm Janos! I work on geometry processing, optimization, and computer graphics.

I studied math at the University of Bonn. In my bachelor's I did algebraic geometry, and in my master's I switched to PDE-constrained optimization.

These days I work on Roblox's game engine. Mostly that means geometry processing, but I also get to work on collision, networking, and graphics. Before that I was at nTop, building SDF-based modeling tools that make it easy to design complex, high-performance parts.

Projects

  • YUBI gripper for the YAM arm Toyota and AIRoA's open YUBI gripper, adapted to work on the YAM arm. GitHub
  • Mantis Really fast distance queries to triangle meshes, sped up with SIMD. GitHub
  • Onion A little chess engine I wrote, with a WebGPU renderer that draws everything using SDFs. Fair warning: it might make you cry. Play GitHub
